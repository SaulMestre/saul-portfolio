# Product brief

## Objective

Present the owner's software projects, technical skills and development process through a portfolio that is itself a credible engineering demonstration.

## Experience

- Home: a simple chat-first experience, with the primary invitation Pregúntame / Ask me and featured projects below. Final visual composition and copy remain open. Until the conversational engine exists, the entry point must honestly show its unavailable state.
- Projects: case studies covering problem, solution, architecture, technologies, development, challenges and verified status.
- Technologies and methodology: practical use of tools, specification-driven and AI-assisted development.
- Timeline: playful illustrated horizontal journey with an evolving side-profile character. Begin with a crawling baby, transition to a walking child and then an older character. Advance between milestones; support multiple milestones in one year, backward navigation, keyboard controls and a reduced-motion/list alternative. Exact biography and art style require owner approval before public publication.
- Ask me: public natural-language chat about approved professional information, with a live panel showing covered topics and structured decision events. Support grounded answers, uncertainty, off-topic handling, restricted requests and contextual follow-ups. Never expose hidden reasoning or private information.
- Contact: owner-approved professional contact options.
- Administration: authenticated content and knowledge management; analytics only within an approved privacy policy.

## Proposed delivery order

1. Governance and repository foundation.
2. Application skeleton, localization, navigation, local development and CI.
3. Minimal chat-first home with honest availability state and approved featured content when available.
4. Conversational engine, approved knowledge, safety controls, evaluation and event panel.
5. Project case studies and timeline interactions with approved content and illustrations.
6. Admin, deployment, performance, accessibility and privacy verification.

The order can change with owner approval. Each phase requires a feature specification and acceptance criteria before implementation.

## Open decisions

Visual identity, complete project inventory, public biography and contact content, AI provider, knowledge retrieval approach, session persistence and retention, hosting configuration, and any shared engine extraction. No commercial project's private code or data is assumed available for publication.
