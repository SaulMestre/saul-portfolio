# Development

This is an application bootstrap, not a production portfolio. Toolchains:
Node.js 24.22.3 and .NET SDK 10.0.404. The initial public shell uses Spanish
and English routes and is deliberately noindex. The current server deployment
mode allows locale redirection; static export remains a future deployment
decision. No database, paid API or secret is required.

## Local commands

```sh
cd frontend
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

From the repository root:
```sh
dotnet restore backend/Portfolio.slnx --locked-mode
dotnet test backend/Portfolio.slnx --no-restore
dotnet run --project backend/src/Portfolio.Api --no-restore -- --urls http://localhost:5080
```

GET http://localhost:5080/health reports the health of the running API only.

## Bootstrap dependency locks

The initial lockfiles were generated by the bootstrap CI run 45638425898.
The regular CI workflow restores exclusively in locked mode. Update lockfiles
only through deliberate dependency changes, review their diffs, and rerun CI.
CI runs on Ubuntu 24.04 to support the pinned Playwright browser tooling.

## Spec Kit

The official Specify CLI v1.4.4, pinned to upstream commit
`c8133f463a586879e3af6dfd2864beb8995a8764`, was installed and used to generate
an isolated Copilot integration with Python scripts in CI run 45655298305.
The generated archive was verified against the recorded SHA-256 digest and
its managed-file manifests. The agent skills contain automatic extension-hook
instructions; their publication was not approved through the connector.
The generated integration is therefore not installed in this repository.
The temporary preview workflow is removed. The existing constitution,
repository instructions, and specification-driven workflow remain authoritative.
Any future adoption of managed agent skills requires a separate review and
explicit approval. No extension hooks are enabled as part of this change.
