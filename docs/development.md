# Development

This is an application bootstrap, not a production portfolio. Toolchains:
Node.js 24.22.3 and .NET SDK 10.0.404. The initial public shell uses Spanish
and English routes and is deliberately noindex. The current server deployment
mode allows locale redirection; static export remains a future deployment
decision. No database, paid API or secret is required.

## Local commands

```sh
cd frontend
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

From the repository root:
```sh
dotnet restore backend/Portfolio.slnx --locked-mode
dotnet test backend/Portfolio.slnx --no-restore
dotnet run --project backend/src/Portfolio.Api --no-restore -- --urls http://localhost:5080
```

GET http://localhost:5080/health reports the health of the running API only.

with Python scripts in CI run 45655298305. The original archive SHA-256 is

To install the CLI locally (Python 3.11+ and uv required):

```sh
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@c8133f463a586879e3af6dfd2864beb8995a8764
specify version
python scripts/verify_spec_kit.py
```

### Required repository rules (owner configuration)

Create an active branch ruleset targeting `main` in repository Settings > Rules > Rulesets. Require a pull request before merging, require the four checks `Engineering checks / frontend`, `Engineering checks / backend`, `Engineering checks / spec-kit`, and `Secret scanning / secrets` (select the actual check contexts from successful runs), require up-to-date branches, block force pushes and deletion, and do not add routine bypass actors. The owner retains review responsibility; do not require an independent approval until a separate reviewer is available, because GitHub does not permit authors to approve their own PRs. Verify the actual rule in the UI; this connector cannot read or change rulesets.
