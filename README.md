# Saül Portfolio

A personal software engineering portfolio that presents real projects, technical decisions, development practices and an interactive demonstration of conversational AI.

## Planned experience

- Project case studies and verified technology choices.
- Professional profile and development methodology.
- An illustrated, milestone-driven timeline with an evolving character.
- A grounded conversational assistant with a public, structured decision-event panel.
- Private administration for approved public content and knowledge.

## Proposed stack

React, TypeScript, ASP.NET Core, PostgreSQL, GitHub Actions and Render. AI providers will be behind a replaceable interface.

## Status

Planning. No application functionality is implemented yet. See the [project constitution](.specify/memory/constitution.md) and [product brief](docs/product-brief.md).

This repository is public for inspection. Credentials, private data and proprietary third-party code must never be committed. No open-source license has been granted at this stage.
